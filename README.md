## Featured Projects

### Resource-Constrained Video Anomaly Detection
> Real-time anomaly detection for CPU-only edge environments — no GPU, no cloud.

Fuses a **One-Class SVM** with a lightweight **Autoencoder** (80 parameters) to detect motion anomalies in surveillance footage. Achieves **AUC-ROC: 0.64–0.65** on the UCSD Ped2 benchmark across 2,010 test frames.

`PyTorch` `OpenCV` `Scikit-Learn` `NumPy` `JobLib`

---

### Adversarial Robustness of ML Pipelines in Smart Agriculture
> Multi-stage ML pipeline for crop recommendation on a 2,200-sample, 22-class dataset.

Extends beyond standard classification to include ensemble distillation into interpretable farming rules, climate-shift stress testing, **adversarial robustness analysis across all 21 feature pairs**, and dead-zone detection via K-Means clustering.

`Scikit-Learn` `SHAP` `PyTorch` `NetworkX` `NumPy` `Seaborn`

---

### p-Center Facility Location — Genetic Algorithm Solver
> Heuristic solver for the NP-hard p-Center location problem.

Designed and implemented a **Genetic Algorithm-based solver** in Python, benchmarked across **40+ datasets** to evaluate solution quality and convergence behaviour.

`Python` `NumPy`
